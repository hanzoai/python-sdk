# hanzo-tools-plan

Plan orchestration tools for Hanzo AI MCP (HIP-0300).

## Tools

- `plan` - Structured task planning and orchestration

## Installation

```bash
pip install hanzo-tools-plan
```

## Usage

```python
from hanzo_tools.plan import TOOLS, register_tools

# Register with MCP server
register_tools(mcp_server)
```
